# Product requirements

Build a complete, fast Bible scramble party game. The attached owner brief is the specification; the full text is retained in MASTER_BUILD_PROMPT.md.

## Priorities and acceptance

1. Party: one device, 2–8 editable teams, categories/difficulty, timer, rounds, questions, scoring/penalties/undo, skips/reveal, pause/resume, round results, ties and replay. No runtime backend or account dependency after initial page load.
2. Polish: responsive game-show visual language, keyboard controls, optional generated audio, reduced motion, readable projector mode.
3. Host/display: phone host and separate presentation-only display synchronized through an authoritative room server.
4. Online: private codes/links/QR, named players and lobby team switching, deterministic first buzz, typed and verbal modes, host authorization, reconnect and expiry.
5. Solo: selectable categories/difficulty, typed answers, hint, streaks, personal best stored locally.
6. Quality: 200+ unique validated entries, unbiased shuffling with nonidentity fallback, no repeat within a game, meaningful automated tests and documentation.

No fictional results, credentials, or private data may be published. Every delivery checkpoint must be committed, pushed, and checked against the remote.
